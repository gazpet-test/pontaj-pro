## Deciziile agentului de migrare (r1, rămân valabile)
| Subiect | Decizie | De ce |
|---|---|---|
| `valoare_lei` (§4) | privilegii de coloană: `authenticated` nu are SELECT/INSERT/UPDATE pe coloană; UI citește `red_v_parcele`; valoarea prin `fn_red_valoare_parcela` / `fn_red_valoare_parcela_seteaza` (admin) | mascare reală în BD, nu doar în UI; costul: `select=*` pe tabel pică (documentat în contract) |

| service_role | SELECT/INSERT/UPDATE pe tabele, ocolește RLS, dar `fn_red_nivel()` = NULL ⇒ numerotarea / valoarea îl refuză | edge-urile nu există încă; se deschide explicit când apare nevoia |

## Ce verifică migrarea singură
Precondiții: marcajul `gazpet.livrare_migrare = '20261126a_redari_teren:<txid>'`, `postgres`, nimic `red_*` / `fn_red_*` / bucket / politici

`user_module_access.access_level` cu admin/editor/viewer, RLS pe `storage.objects`.

`TO authenticated`; pe jurnal / numere / token / rate_limit doar SELECT; meta doar SELECT/INSERT), anon fără niciun privilegiu, nimeni cu
DELETE/TRUNCATE, jurnal fără INSERT/UPDATE pentru roluri, `valoare_lei` fără privilegii pentru authenticated, tokenul izolat, meta izolată,
`seq` identity, indexul unic pe `cheie_sursa`, 11 trigger-e de jurnal + 2 de imutabilitate + 10 de legături, 19 funcții toate SECURITY DEFINER
cu `search_path = public, pg_temp` (22 după r4: + `fn_red_rate_limit_curata`, `fn_red_raspunsuri_valideaza`, `fn_red_storage_expr_bucket`), EXECUTE exact pe listele așteptate

care să poată acoperi `redari`, indexul pe `red_rate_limit.fereastra_start`, cheia de modul fără niciun drept acordat.
